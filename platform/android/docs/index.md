## Open-Source Apps Using MapHero Android

You can learn how to use the API from MapHero Android by stuying the source code of existing apps that intergrate MapHero Android. Here are some open-source apps that use MapHero Android:

- [Streetcomplete](https://github.com/streetcomplete/StreetComplete) ([source code](https://github.com/search?q=repo%3Astreetcomplete%2FStreetComplete%20maplibre&type=code))
- [The official Wikipedia app for Android](https://github.com/wikimedia/apps-android-wikipedia) ([source code](https://github.com/search?q=repo%3Awikimedia%2Fapps-android-wikipedia%20maplibre&type=code)).
- [MapHeroAndroidTestApp](https://github.com/maplibre/maplibre-native/tree/main/platform/android/MapHeroAndroidTestApp). This app is part of the MapHero Native repository and is used for (automated) testing. Many of the examples in this documentation site come directly from this app.
